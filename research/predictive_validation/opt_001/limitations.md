# OPT-001 / PV-001

# Limitations

- PV-001 evaluates predictive validity only; it does not evaluate economic utility.
- SPY OHLCV cache begins in 2008, so predictive validation is shorter than the full VIXCLS history.
- OPT-001 is a VIXCLS-based index-level construct and does not decompose the option-implied volatility surface.
- Predictive relationships are evaluated against predefined statistical baselines, not trading benchmarks.
- Directional return analysis is included as a preregistered target but should not be interpreted as strategy evidence.
- No trading performance, alpha generation, Sharpe, CAGR, portfolio return, or production deployment claim is made.

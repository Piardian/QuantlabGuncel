# BRD-001 / PV-001: Limitations

## Predictive Scope

PV-001 evaluates statistical predictive information only.

It does not evaluate economic utility.

## No Trading Evaluation

PV-001 does not run trading strategies, portfolio simulations, or production workflows.

## Universe Limitation

BRD-001 uses a fixed current universe, not survivorship-free historical constituents.

## Event Definition Limitation

Binary risk events were defined using fixed distributional event rates for validation diagnostics.

They are not optimized trading thresholds.

## Return Hypothesis Limitation

Future return association was not supported in the preregistered direction.

This does not imply BRD-001 has no use; it limits the supported use case to risk-state prediction.

## Forbidden Conclusions

PV-001 does not support claims about:

- trading profitability
- alpha
- portfolio performance
- economic value
- production deployment

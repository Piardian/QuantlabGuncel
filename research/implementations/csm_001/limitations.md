# CSM-001 / IM-001 Limitations

## Data Limitation

The implementation requires an externally provided adjusted-close panel and universe governance. IM-001 does not solve survivorship-free historical constituency.

## Validation Limitation

Unit verification uses synthetic data. Empirical construct validation belongs to CV-001.

## Scope Limitation

IM-001 does not evaluate predictive power, returns, alpha, economic value, turnover, transaction costs, crash risk, or production suitability.

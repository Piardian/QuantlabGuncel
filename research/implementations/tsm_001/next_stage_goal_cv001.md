# TSM-001 / CV-001 Construct Validation

## Purpose

Evaluate whether the implemented TSM-001 construct behaves as a stable, reproducible and internally consistent implementation of frozen CD-001 on real data.

## Allowed

- Coverage analysis
- State distribution
- Positive / negative / neutral state frequency
- Persistence of state labels
- Reproducibility checks
- Data quality reporting

## Forbidden

- No future returns
- No alpha
- No trading strategy backtest
- No economic validation
- No volatility scaling
- No production recommendation

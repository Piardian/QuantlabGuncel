# Scientific Identity

## Construct ID

`VOL-001`

## Scientific Name

US Equity Market Daily Yang-Zhang Volatility State

## Primary Category

**Volatility State / Risk Forecasting Construct**

## Core Identity

VOL-001 measures the current realized volatility state of the US equity market using SPY daily OHLC data and the Yang-Zhang estimator.

The construct is best understood as a daily realized market turbulence sensor.

## What It Represents

Supported by evidence:

- realized volatility state
- market turbulence
- overnight gap variation
- open-to-close variation
- range-based intraday variation
- volatility persistence
- future volatility-state risk

## What It Does Not Represent

Not supported:

- alpha
- direct return prediction
- option-implied volatility
- GARCH conditional variance
- intraday high-frequency realized variance
- cross-sectional dispersion
- exact drawdown forecasting

## Scientific Confidence

**High for volatility-state identity.**

**Partial for economic utility.**

**Not supported for alpha.**

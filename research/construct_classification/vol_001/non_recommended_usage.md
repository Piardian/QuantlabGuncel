# Non-Recommended Usage

## Not Supported

VOL-001 should not be used or described as:

- standalone alpha signal
- direct buy/sell system
- direct directional return predictor
- exact drawdown predictor
- options-implied volatility proxy
- VIX replacement
- GARCH conditional-volatility model
- ATR replacement
- intraday realized-volatility engine
- cross-sectional dispersion construct

## Specific EV-001 Caution

The dynamic de-risking use case was **Not supported** in EV-001.

Therefore VOL-001 should not be generalized into aggressive de-risking logic without a new preregistered study.

## Boundary

Absence of support is not proof that these uses can never work.

It means they are not supported by the completed VOL-001 evidence body.

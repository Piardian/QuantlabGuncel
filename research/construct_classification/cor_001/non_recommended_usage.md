# Non-Recommended Usage

## Not Recommended

Do not use COR-001 as:

- a standalone alpha signal
- a directional return forecast
- a buy/sell rule
- a universal market timing engine
- a production risk engine without operational validation
- a justification for leverage expansion solely because correlation is low

## Reason

The evidence supports risk-state and risk-management utility.

It does not support return prediction, alpha generation, or unrestricted production use.

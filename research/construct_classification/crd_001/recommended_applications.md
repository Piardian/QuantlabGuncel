# Recommended Applications

## Supported Or Partially Supported Uses

CRD-001 is appropriate as a scientific sensor for:

- high-yield credit stress monitoring
- credit-market risk dashboards
- portfolio risk context
- credit-stress-aware risk budgeting support
- volatility-aware de-risking support
- drawdown-warning support with caution
- portfolio risk-control monitoring

## Usage Boundary

These applications are supported only within the available evidence body and evaluated workflows.

CRD-001 should be treated as a risk-state construct, not as a standalone alpha signal.

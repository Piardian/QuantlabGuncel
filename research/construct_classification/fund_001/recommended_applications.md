# FUND-001 / CC-001

# Recommended Applications

| application | classification | rationale |
| --- | --- | --- |
| Research monitoring of short-term financial funding spread stress | Supported by evidence | Construct is reproducible and tracks CP-Tbill spread states. |
| Risk-dashboard sensor for funding conditions | Partially supported | Predictive risk information exists, but economic utility workflows failed. |
| Input to future hypothesis generation | Supported by evidence | PV/HV provide structured evidence for future preregistered studies. |
| Standalone portfolio risk-control rule | Not supported | EV-001 use cases were not supported. |

## Interpretation

Recommended applications are limited to research and monitoring contexts. Economic deployment is not supported by EV-001.

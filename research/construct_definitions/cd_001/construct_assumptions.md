# Construct Assumptions

## Core Assumptions

1. **SPY is a valid proxy for the US equity market.**
2. **Market regime is latent rather than directly observed.**
3. **Two states are sufficient for the first preregistered construct definition.**
4. **Daily return and realized volatility contain the minimum stable information needed to identify broad market states.**
5. **The fitted state labels can be ordered ex post by state characteristics without changing the underlying construct.**

## Modeling Assumptions

1. The latent state process follows first-order Markov dynamics.
2. Emission distributions are adequately represented by a Gaussian HMM.
3. The state probabilities estimated from the available sample are stable enough to support preregistered research.
4. Realized volatility computed from a 20-day window is an acceptable summary of local risk conditions.

## Interpretive Assumptions

1. Higher-return / lower-volatility states correspond to a broad **Expansion / Risk-On** condition.
2. Lower-return / higher-volatility states correspond to a broad **Stress / Risk-Off** condition.

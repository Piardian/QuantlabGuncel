# Stability Analysis

Stability over time requires a valid MR-001 latent state sequence.

Because the repository does not contain a verified implementation of the CD-001 HMM construct, stability of MR-001 cannot be assessed directly.

## What the proxy output suggests

The available rule-based regime sensitivity output shows that:

- BULL states dominate the sample
- NEUTRAL and BEAR states occur less frequently
- correlations between simple SPY regime features and trade R are small in magnitude

However, this is only evidence about the proxy rule-based sensitivity study, not about MR-001 itself.

## Conclusion

**Inconclusive**

# Temporal Stability

## Scope

This file evaluates descriptive stability over time. It does not assess forecasting ability.

## Available Coverage

The validation sample runs from 2023-07-31 to 2026-07-27.

## Year-Level Stability

Year-level summaries are written to:

```text
temporal_stability_by_year.csv
```

Month-level summaries are written to:

```text
temporal_stability_monthly.csv
```

## Assessment

Partially supported. CRD-001 produces continuous observations across the available period and normalized observations after warmup. The sample is too short to validate stability across several credit cycles.

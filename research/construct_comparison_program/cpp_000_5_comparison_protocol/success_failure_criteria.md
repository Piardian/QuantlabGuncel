# CPP-000.5

# Success and Failure Criteria

## Program-Level Success

CPP succeeds if it produces an evidence-supported Construct Information Matrix describing overlap, incremental information, redundancy, orthogonality, complementarity, hierarchy, and limitations across the frozen construct ecosystem.

## Analysis-Level Success

An analysis succeeds if it:

- follows the preregistered method,
- meets sample thresholds,
- reports corrected inference where applicable,
- reports robustness checks,
- uses bounded interpretation language.

## Failure / Inconclusive Conditions

Classify as Inconclusive if:

- sample thresholds fail,
- missingness dominates the result,
- direction is unstable,
- multiple-testing correction removes support,
- results depend on one period or one sample definition,
- required construct output cannot be identified.

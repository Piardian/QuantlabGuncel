# CPP-000

# Program Scope

## In Scope

- Comparing completed constructs as frozen scientific objects.
- Measuring information overlap, redundancy, orthogonality, complementarity, and incremental information.
- Studying multivariate information architecture.
- Studying lead-lag relationships as temporal associations only.
- Building an evidence-weighted construct ecosystem taxonomy.

## Out of Scope

- Construct redesign.
- Parameter optimization.
- New construct discovery.
- Trading strategy design.
- Alpha discovery.
- Entry/exit/risk rule optimization.
- Production recommendations.
- Causal claims without causal identification.

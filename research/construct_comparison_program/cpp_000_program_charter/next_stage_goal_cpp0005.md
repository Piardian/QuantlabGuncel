# RESEARCH PROGRAM

Construct Comparison Program (CPP)

CPP-000.5

Comparison Protocol Registration

--------------------------------------------------

## BACKGROUND

CPP-000 established the Program Charter and Frozen Evidence Registry for the Construct Comparison Program.

The frozen construct universe is:

- MR-001
- LIQ-001
- VOL-001
- BRD-001
- COR-001
- CRD-001
- FUND-001
- OPT-001

No statistical comparison has been performed.

--------------------------------------------------

## PURPOSE

Pre-register the complete statistical comparison protocol before any data alignment, dependence mapping, incremental information analysis, redundancy analysis, or lead-lag analysis begins.

This stage prevents researcher degrees of freedom and post-hoc method selection.

--------------------------------------------------

## REQUIRED SPECIFICATION

Define and freeze:

- primary comparison questions,
- confirmatory vs exploratory analyses,
- significance level,
- multiple-comparison correction method,
- minimum sample-size rules,
- missing-data policy,
- common-sample vs maximum-sample policy,
- construct output selection policy,
- transformations and normalization policy,
- pairwise dependence methods,
- conditional and multivariate methods,
- incremental information methods,
- redundancy and orthogonality classification rules,
- complementarity classification rules,
- lead-lag analysis rules,
- robustness and sensitivity rules,
- interpretation language standards,
- failure and success criteria.

--------------------------------------------------

## FORBIDDEN

Do NOT:

- run statistical analysis,
- inspect results,
- optimize methods,
- modify constructs,
- change frozen evidence,
- make comparison conclusions.

--------------------------------------------------

## EXPECTED OUTPUTS

Generate:

- `cpp0005_comparison_protocol.md`
- `statistical_method_registry.md`
- `analysis_preregistration.csv`
- `classification_rules.md`
- `missing_data_policy.md`
- `multiple_testing_policy.md`
- `robustness_plan.md`
- `interpretation_standards.md`
- `executive_summary.md`

--------------------------------------------------

## SUCCESS CRITERIA

CPP-000.5 is successful only if the complete comparison protocol is frozen before any statistical analysis begins.

After CPP-000.5, proceed to CPP-001 only with human approval.

# CPP-007 Architecture Limitations

## Main Limitation

The current information architecture is limited to pairwise association evidence. This is insufficient for full scientific organization of the construct ecosystem.

## Unanswered Architecture Questions

- Which constructs add independent information beyond the others?
- Which constructs are conditionally redundant?
- Which construct combinations are complementary?
- Which constructs are upstream or downstream in a lead-lag sense?
- Whether high pairwise association reflects shared mechanism, common market stress exposure, measurement overlap, or third-factor mediation.

## Required Future Evidence

A complete architecture requires eligible incremental, multivariate, robustness, and lead-lag analyses under a preregistered sample protocol.

## Scientific Boundary

No complete construct ecosystem taxonomy is supported by CPP-007.

# Version 3.0 Research Program

This directory is the working index for the Market Signal Discovery Program v3.0.

## Purpose

Discover new predictive constructs rather than explain the behavior of an existing production signal.

## Stage Gating

Research proceeds only when the previous stage is completed successfully:

1. `RP` - Research Prioritization
2. `LR` - Literature Review
3. `CD` - Construct Definition
4. `IM` - Implementation
5. `CV` - Construct Validation
6. `MI` - Mechanism Identification
7. `HV` - Hypothesis Validation
8. `PV` - Predictive Validation
9. `EV` - Economic Validation
10. `CC` - Construct Classification
11. `FSR` - Final Scientific Review

## Working Rule

Every candidate construct is treated as a hypothesis to be tested, not a rule to be improved.
The program should favor preregistration, reproducibility, and clean rejection of weak ideas.

## Suggested Artifact Layout

- `lr_###/` for literature review outputs
- `cd_###/` for construct definition outputs
- `im_###/` for implementation outputs
- `cv_###/` for construct validation outputs
- `mi_###/` for mechanism identification outputs
- `hv_###/` for hypothesis validation outputs
- `pv_###/` for predictive validation outputs
- `ev_###/` for economic validation outputs
- `cc_###/` for construct classification outputs
- `fsr_###/` for final scientific review outputs

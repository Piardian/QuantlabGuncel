# Spread Widening Episode Analysis

## Definition Used For Description

A descriptive widening episode date is any valid CRD-001 observation where the 20-day spread change is at or above the 90th percentile of available 20-day spread changes.

This is not an optimized threshold and not a trading rule.

## Result

- 20-day widening threshold: 0.3110
- Episode-date count: 51

Episode dates are written to:

```text
spread_widening_episodes.csv
```

## Interpretation

Supported by evidence within the available sample: CRD-001 can identify dates with unusually large contemporaneous high-yield spread widening.

Inconclusive: whether those episodes correspond to broad historical credit crises, because the available data range is limited.

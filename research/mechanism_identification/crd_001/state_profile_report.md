# State Profile Report

## State Buckets

- LOW_CREDIT_STRESS: percentile <= 0.20
- MID_CREDIT_STRESS: 0.20 < percentile < 0.80
- HIGH_CREDIT_STRESS: percentile >= 0.80

These buckets are descriptive profiling groups only.

## Observed Profile

High credit-stress states show higher average HY OAS than low credit-stress states.

```text
High mean HY OAS: 3.6431
Low mean HY OAS: 2.7726
Difference: 0.8705
```

## Interpretation

Supported by evidence within the available sample: the state buckets mechanically and coherently separate tighter from wider high-yield spread environments.

Partially supported: broader credit-cycle interpretation, because the sample does not include multiple major credit cycles.

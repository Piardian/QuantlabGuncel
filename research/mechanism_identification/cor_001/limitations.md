# MI-001 Limitations

## Contemporaneous Only

MI-001 uses same-day construct and market-condition data.

It does not evaluate forecasting ability.

## No Causal Claims

MI-001 cannot determine whether correlation causes volatility, volatility causes correlation, or both reflect another market process.

## Limited Peer Construct Availability

BRD-001 output was available for contemporaneous comparison.

VOL-001, LIQ-001, and MR-001 output files were not used in this MI-001 profile because ready construct output files were not present in the output directory at execution time.

## Pearson Correlation Scope

COR-001 measures linear average pairwise correlation.

It does not directly measure nonlinear dependence, tail dependence, or implied correlation.

## Universe Limitation

The fixed current universe may create survivorship bias.

## No Economic Interpretation

MI-001 does not evaluate:

- trading performance
- alpha
- future returns
- portfolio utility
- production suitability

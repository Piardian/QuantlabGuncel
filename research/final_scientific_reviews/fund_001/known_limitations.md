# FUND-001 / FSR-001

# Known Limitations

- FUND-001 is based only on DCPF3M - DTB3.
- DCPF3M availability limits historical coverage.
- The construct is not a pure funding-liquidity measure.
- Component mechanisms cannot be fully separated using only the frozen inputs.
- Credit-stress predictive validation has short overlap.
- EV-001 failed across all predefined risk-management workflows.
- No transaction costs, hedge implementation, taxes, financing costs, or live validation were included.
- No production readiness is supported.

# FUND-001 / FSR-001

# Recommended Applications

| application | classification | rationale |
| --- | --- | --- |
| Research-grade funding spread monitoring | Supported by evidence | Formula and implementation are stable and reproducible. |
| Input to future preregistered risk research | Supported by evidence | PV-001 showed some predictive-risk information. |
| Risk dashboard context sensor | Partially supported | Useful as context, but economic workflow utility failed. |
| Production risk overlay | Not supported | EV-001 did not support predefined workflows. |
| Standalone alpha/trading signal | Not supported | Not tested for alpha and economic workflows failed. |

## Boundary

Recommended applications are research and monitoring applications only. Production risk-control usage is not supported by current evidence.

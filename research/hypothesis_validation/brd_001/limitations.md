# BRD-001 / HV-001: Limitations

## Explanatory Scope

HV-001 validates same-day and trailing explanatory mechanisms.

It does not evaluate future outcomes.

## H1 Construct-Internal Limitation

H1 is partly definitional because LOW_BREADTH and HIGH_BREADTH are created from BRD-001 itself.

H1 should not be interpreted as independent external mechanism evidence.

## Period Balance Limitation

Cross-period direction is stable, but period sample balance is imperfect.

The 2022-2025 block contains only 14 HIGH_BREADTH observations.

## Universe Limitation

BRD-001 uses a fixed current universe, not survivorship-free historical constituents.

## Statistical Tool Limitation

SciPy was not available in the local environment.

HV-001 used deterministic permutation tests instead of Mann-Whitney tests.

## Forbidden Conclusions

HV-001 does not support claims about:

- prediction
- profitability
- alpha
- trading edge
- economic value
- production deployment

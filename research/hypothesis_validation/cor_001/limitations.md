# HV-001 Limitations

## Explanatory Validity Only

HV-001 evaluates contemporaneous mechanism hypotheses.

It does not evaluate forecasting ability.

## No Causality

The study cannot determine whether high correlation causes volatility, drawdown, or breadth weakness.

It only evaluates whether the preregistered contemporaneous mechanism is empirically supported.

## Construct-Internal Hypothesis

H4 is partly construct-internal because COR-001 state groups are defined using COR-001 percentile.

Therefore H4 is interpreted as state-separation evidence, not independent mechanism evidence.

## Limited Alternative-Construct Outputs

BRD-001 was available for direct comparison.

VOL-001, LIQ-001, and MR-001 outputs were not included in this formal HV-001 test.

## Data Limitations

The study uses a fixed current universe and Yahoo Finance data.

Survivorship and data-source limitations remain.

## Forbidden Interpretations

HV-001 does not support claims regarding:

- prediction
- future returns
- trading performance
- alpha
- economic value
- production deployment

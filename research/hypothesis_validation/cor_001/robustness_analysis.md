# Robustness Analysis

## Purpose

Evaluate whether HV-001 results depend on extreme observations.

## Method

For each hypothesis variable, the top and bottom 1% of values were trimmed within HIGH_CORRELATION and LOW_CORRELATION groups.

## Result

All hypotheses preserved the expected direction after trimming extremes.

| Hypothesis | Trimmed Difference | Direction Preserved |
| --- | ---: | --- |
| H1 | 0.1485 | Yes |
| H2 | -0.0800 | Yes |
| H3 | -0.2830 | Yes |
| H4 | 0.2392 | Yes |

## Interpretation

Supported by evidence:

The explanatory mechanism does not appear to be driven solely by extreme observations.

Boundary:

This robustness analysis does not evaluate prediction, trading performance, or economic utility.

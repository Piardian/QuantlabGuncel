# Decision Framework

WER-002 must classify the workflow execution-realism evidence as exactly one:

- Execution Realism Supported
- Execution Realism Partially Supported
- Execution Realism Not Supported
- Inconclusive

## Interpretation Rules

Supported execution realism does not imply:

- production approval
- live trading readiness
- regulatory suitability
- brokerage-level execution accuracy

Not supported execution realism does not invalidate:

- CSM-001
- TSM-001
- the scientific nested workflow relationship

It only means the evaluated workflow did not survive the registered execution-realism assumptions.

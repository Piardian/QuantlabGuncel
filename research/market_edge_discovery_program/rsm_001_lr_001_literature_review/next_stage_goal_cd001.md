# RSM-001 / CD-001 Construct Definition

Purpose: freeze one precise, reproducible Residual Momentum construct definition based on LR-001.

CD-001 must answer:

- Which factor model is used for residualization?
- Which return frequency is used?
- Which regression window is used?
- What minimum observations are required?
- Are returns excess returns or raw returns?
- Is residual momentum volatility-standardized?
- Is RSM a ranking construct or state construct?
- Which alternatives are rejected and why?

Decision priority:

Construct clarity, reproducibility and model-discipline take priority over expected performance.

Forbidden:

- Backtesting
- Parameter optimization
- Alpha claims
- Production recommendations
- Selecting the risk model after seeing results

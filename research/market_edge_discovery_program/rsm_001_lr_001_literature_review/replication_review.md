# Replication Review

Residual Momentum is replicable in principle, but requires more modeling choices than CSM-001.

Replication requirements:

- Public factor data.
- Deterministic security return panel.
- Fixed regression window.
- Fixed minimum-observation policy.
- Fixed residual aggregation method.
- Fixed ranking or state definition.

Replication risk:

Two researchers can produce different RSM results if they choose different factor models or regression windows.

Therefore CD-001 must eliminate ambiguity.

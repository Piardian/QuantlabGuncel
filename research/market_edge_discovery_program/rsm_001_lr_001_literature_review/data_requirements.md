# Data Requirements

RSM-001 requires:

- Adjusted security prices or returns.
- Factor return series.
- Risk-free rate if excess returns are used.
- Trading calendar.
- Sufficient return history.

Potential public factor sources:

- Kenneth French data library.
- Other predefined public factor datasets if justified.

Data risk:

Moderate.

Unlike PEAD and PROF, RSM does not require earnings timestamps or accounting statement publication dates.

# Canonical Definitions

Residual Momentum generally means:

Momentum measured using residual returns after controlling for common factor exposures.

Generic construction:

1. Regress each security's returns on a predefined set of factor returns.
2. Extract residual returns.
3. Aggregate prior residual returns over a formation window.
4. Rank or classify securities using residual momentum.

Important boundary:

Residual Momentum is not volatility scaling alone.

Residual Momentum is not industry-neutral momentum unless industry factors are the residualization model.

Residual Momentum is not raw cross-sectional momentum.

# Regression Design Considerations

RSM requires regression design choices.

Key dimensions:

- Return frequency: daily or monthly.
- Regression window length.
- Minimum observations required.
- Rolling versus expanding regressions.
- Excess returns versus raw returns.
- Factor alignment.
- Missing return treatment.

Important risk:

Regression design can materially change residuals.

CD-001 must freeze the design before empirical validation to avoid researcher discretion.

# Executive Summary

RSM-001 / LR-001 is complete.

Main conclusion:

Residual Momentum is a scientifically meaningful momentum construct that attempts to isolate idiosyncratic continuation by removing common factor exposures from prior returns.

The construct is more feasible than PEAD-001 and PROF-001 because it can be built from price-return data and public factor returns.

The main methodological risk is factor-model and regression-window discretion.

No construct was frozen and no predictive or economic claim was made.

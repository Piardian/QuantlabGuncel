# Measurement Families

## Canonical Cross-Sectional Momentum

Rank securities by prior medium-horizon returns and compare winners with losers. Common formation windows include 3 to 12 months, often with a skip period.

## 12-1 Momentum

Uses prior 12-month return excluding the most recent month. This is a common academic convention, but LR-001 does not freeze it as CSM-001.

## 6-1 and 3-1 Momentum

Shorter formation windows measure more recent relative strength. These may capture different behavior and turnover characteristics.

## Industry Momentum

Ranks industries or adjusts for industry effects. This can separate stock-specific momentum from industry-level continuation.

## Residual Momentum

Ranks residual returns after controlling for common factors. Intended to isolate idiosyncratic continuation.

## Risk-Adjusted Momentum

Uses volatility-scaled or beta-adjusted prior returns. These definitions blend momentum measurement with risk normalization.

## Long-Only Momentum

Uses only the winner side or top-ranked securities. This differs from canonical long-short academic tests and requires separate economic validation.

## LR-001 Boundary

This taxonomy does not choose a measurement family. CD-001 must freeze exactly one operational definition before empirical validation.

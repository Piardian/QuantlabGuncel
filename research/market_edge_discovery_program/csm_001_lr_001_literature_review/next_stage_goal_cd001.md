Transform LR-001 into one precise and frozen Cross-Sectional Momentum construct definition.

- Universe requirements
- Eligible security rules
- Formation return definition

- Run tests
- Optimize parameters
- Compare profitability
- Select rules because they appear profitable
- Recommend production deployment

# Executive Summary

CSM-001 / CD-001 freezes the construct as:

**Canonical 12-1 Cross-Sectional Momentum State**.

For each eligible security, CSM-001 computes prior adjusted-price return from `t-252` to `t-21`, ranks securities cross-sectionally on date `t`, and outputs a percentile score plus top-decile flag.

This is a construct state only. It is not a trading strategy, portfolio rule, alpha claim, profitability claim or production recommendation.

The definition is now frozen. The next stage is IM-001, whose only purpose is faithful deterministic implementation.

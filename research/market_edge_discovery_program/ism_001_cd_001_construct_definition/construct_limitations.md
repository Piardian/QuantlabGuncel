# Construct Limitations

- ISM-001 is industry-level, not stock-level.
- It does not assign industries to individual stocks.
- It does not use point-in-time GICS/SIC/NAICS membership.
- It depends on Ken French portfolio construction conventions.
- It uses value-weighted industry returns only.
- It does not evaluate predictive validity.
- It does not evaluate economic value.
- It does not imply production readiness.

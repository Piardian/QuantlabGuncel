# Alternative Definitions Review

## Current Stock-Level Industry Classification

Rejected for ISM-001 because current classifications can introduce look-ahead bias when applied historically.

## Point-In-Time GICS / SIC / NAICS

Not selected because verified point-in-time membership data is not available in the repository.

## Equal-Weighted Industry Returns

Rejected for ISM-001 to reduce small-stock/microcap sensitivity and keep one frozen definition.

## Stock-Level Parent-Industry Signal

Rejected for ISM-001 because it requires reliable historical stock-to-industry membership.

## Lead-Lag Industry Construct

Rejected for ISM-001 because it requires a separate relation graph and represents a different construct family.

# GOAL

Begin:

CWS-001

Composite Workflow Scientific Evaluation

CSM-001 x TSM-001

Mission
-------

CWP-001 registered the protocol for evaluating whether frozen CSM-001 and frozen TSM-001 support a scientifically meaningful composite workflow.

The purpose of CWS-001 is to execute that preregistered protocol.

This is NOT a construct definition study.

This is NOT production research.

This is NOT strategy optimization.

--------------------------------------------------

Primary Research Question

Does the preregistered CSM-001 x TSM-001 composite workflow provide scientifically meaningful information beyond the individual frozen construct states?

--------------------------------------------------

Frozen Inputs

Use only:

- CSM-001 frozen construct outputs
- TSM-001 frozen construct outputs
- CSM-001 FSR conclusions
- TSM-001 FSR conclusions
- CIP-001 interaction evidence
- CWP-001 protocol

--------------------------------------------------

Required Analyses

Perform exactly the analyses preregistered in CWP-001:

1. Frozen input verification
2. Common sample reconstruction
3. State interaction matrix
4. Nested-state confirmation
5. Conditional information analysis
6. Incremental information analysis
7. Conflict-region analysis
8. Time stability analysis
9. Symbol coverage analysis
10. Scientific interpretation

--------------------------------------------------

Forbidden

Do NOT:

- redefine CSM-001
- redefine TSM-001
- create a new construct
- optimize thresholds
- optimize parameters
- build trading strategies
- recommend production deployment
- claim alpha
- perform portfolio optimization

--------------------------------------------------

Expected Outputs

Generate:

- cws001_composite_workflow_evaluation.md
- workflow_state_matrix.csv
- nested_state_analysis.csv
- conditional_information.csv
- incremental_information.csv
- conflict_region_analysis.csv
- time_stability_analysis.csv
- symbol_coverage_analysis.csv
- scientific_interpretation.md
- limitations.md
- executive_summary.md
- cws001_manifest.json

--------------------------------------------------

Allowed Conclusions

Exactly one:

- Workflow Supported
- Workflow Partially Supported
- Workflow Not Supported
- Inconclusive

--------------------------------------------------

Success Criteria

CWS-001 is complete only if it objectively determines whether the CSM-001 x TSM-001 composite workflow is scientifically supported under the preregistered protocol.

No production, profitability, alpha, or deployment conclusion is permitted.

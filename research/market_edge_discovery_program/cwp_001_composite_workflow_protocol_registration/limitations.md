# Limitations

CWP-001 is a protocol registration stage only.

Known limitations carried into CWS-001:

- CSM-001 and TSM-001 retain all limitations from their FSR reports.
- CIP-001 found direct conflict state CSM_HIGH x TSM_LOW had zero observations in the evaluated common sample.
- CSM_HIGH is nested inside TSM_HIGH in the frozen sample, which limits ability to study symmetric disagreement.
- Future CWS-001 results will describe scientific workflow information only.
- No production deployment, live execution, capacity, slippage, tax, or portfolio construction conclusion is authorized.
- No new construct may be inferred solely from a supported workflow result.

Methodological risks:

- Nested constructs can create apparent complementarity if interpretation is not carefully constrained.
- Incremental information metrics can be statistically nonzero while economically irrelevant.
- Composite workflow language can accidentally imply strategy construction; CWS-001 must avoid that interpretation.

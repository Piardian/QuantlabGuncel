# FREE-001 Lifecycle & Survivorship Assessment

## Decision

`PARTIAL`

## Supported

An internal prospective archive can preserve any security observed in a daily symbol-directory snapshot if local persistence is legally permitted.

## Not Supported

The free stack does not currently verify:

- permanent security identifiers
- full ticker-change history
- delisting confirmation
- merger/acquisition linkage
- exchange transfer history
- legal right to retain immutable raw files indefinitely

## Provisional States

The following states remain conceptually feasible but not frozen:

- `ACTIVE`
- `INACTIVE`
- `MISSING`
- `SUSPENDED`
- `DELISTING_SUSPECTED`
- `DELISTED_CONFIRMED`
- `UNKNOWN`

## Result

`SURVIVORSHIP_PRESERVATION = PARTIAL`

This is not enough for formal scientific evidence.

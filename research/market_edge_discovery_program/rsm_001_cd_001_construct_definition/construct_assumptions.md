# Construct Assumptions

- Fama-French 3 factors capture major common equity factor exposures relevant for residual momentum.
- Monthly returns are the appropriate frequency for the initial construct.
- A 36-month rolling window provides enough data for stable residual estimation while remaining responsive.
- A 24-month minimum observation rule avoids extremely weak regressions.
- Residual volatility standardization is part of the construct identity, not a tuned performance enhancement.

These assumptions are methodological, not alpha claims.

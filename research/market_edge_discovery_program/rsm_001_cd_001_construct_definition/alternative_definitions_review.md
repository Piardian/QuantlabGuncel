# Alternative Definitions Review

## CAPM Residual Momentum

Rejected because it only removes market beta and may leave substantial size and value exposure.

## Fama-French 5-Factor Residual Momentum

Rejected for RSM-001 because it adds profitability and investment factors, increasing complexity and reducing comparability with classic residual momentum literature.

## Daily Residual Momentum

Rejected because the initial RSM construct should align with monthly factor data and intermediate-horizon momentum conventions.

## Non-Standard Formation Windows

Rejected because 12-1 is the cleaner academic baseline.

## No Volatility Standardization

Rejected because the selected RSM definition intentionally measures standardized residual momentum.

## Industry Residual Momentum

Rejected because it is closer to industry-neutral momentum and should be a separate construct if studied.

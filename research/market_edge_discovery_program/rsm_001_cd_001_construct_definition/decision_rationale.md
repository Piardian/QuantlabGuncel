# Decision Rationale

RSM-001 selects Fama-French 3-factor standardized 12-1 residual momentum because:

- It is close to the canonical residual momentum literature.
- It directly separates RSM from raw CSM-001.
- It uses public factor data.
- It avoids PEAD/PROF-style point-in-time accounting data barriers.
- It keeps model complexity moderate.
- It preserves a clear scientific question: does factor-residual prior performance form a distinct momentum construct?

This decision is not based on expected performance.

# Data Requirements

Required data:

- Monthly adjusted close panel or monthly security returns.
- Monthly Fama-French 3-factor returns.
- Monthly risk-free rate.
- Security identifier mapping.
- Trading calendar.

Repository status:

Security adjusted close data exists through CSM/TSM output panels.

Fama-French factor data was not found locally during CD-001 inspection and must be obtained or supplied during IM-001.

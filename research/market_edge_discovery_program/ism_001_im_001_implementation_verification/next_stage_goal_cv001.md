# ISM-001 / CV-001 Construct Validation

## Purpose

Evaluate whether the implemented ISM-001 construct demonstrates internal consistency, stability, reproducibility and faithful behavior as a scientific industry momentum construct.

## Allowed

- State distribution analysis
- Rank consistency analysis
- Coverage analysis
- Temporal stability
- Cross-period consistency
- Label stability
- Reproducibility verification

## Forbidden

- Trading backtests
- Return prediction
- Alpha claims
- Economic value
- Portfolio construction
- Parameter tuning
- Construct modification

## Required Outputs

- `cv001_construct_validation.md`
- `state_statistics.csv`
- `coverage_analysis.csv`
- `rank_consistency_report.md`
- `temporal_stability.md`
- `cross_period_consistency.md`
- `reproducibility_report.md`
- `limitations.md`
- `executive_summary.md`

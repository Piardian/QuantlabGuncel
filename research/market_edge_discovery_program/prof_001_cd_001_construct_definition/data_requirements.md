# Data Requirements

PROF-001 requires firm-level accounting data.

Required dataset characteristics:

- Revenue.
- Cost of goods sold.
- Total assets.
- Fiscal period end date.
- Filing date if available.
- Identifier mapping to securities.
- Trading calendar.

Repository inspection found no local accounting statement dataset satisfying these requirements.

IM-001 must therefore begin with dataset ingestion and verification before construct calculation.

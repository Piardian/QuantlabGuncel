# Publication Lag Policy

PROF-001 uses a conservative accounting availability policy.

## If Filing Date Exists

Accounting observation becomes available on the first trading day after filing date.

## If Filing Date Is Missing

Accounting observation becomes available 180 calendar days after fiscal period end.

## Forbidden

- Treating fiscal period end date as data availability date.
- Using accounting statement values before they were public.
- Using restated values without acknowledging restatement risk.

## Rationale

The 180-day fallback is intentionally conservative and frozen before implementation. It is not tuned for performance.

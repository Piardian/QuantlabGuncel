# Decision Rationale

PROF-001 selects gross profitability because:

- It is one of the cleanest profitability definitions.
- It has strong literature support.
- It avoids broad quality-composite discretion.
- It can be expressed with a simple deterministic formula.
- It preserves mechanism clarity.

The main cost is accounting data dependency.

This is acceptable because scientific fidelity takes priority over implementation convenience.

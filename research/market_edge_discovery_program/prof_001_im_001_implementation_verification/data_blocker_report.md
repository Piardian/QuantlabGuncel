# Data Blocker Report

PROF-001 requires accounting statement data.

Missing required dataset:

`data/prof_001/accounting_statements.csv`

Required fields:

- security_id
- ticker
- fiscal_period_end
- revenue
- cost_of_goods_sold
- total_assets

Optional field:

- filing_date

Without these fields, PROF-001 cannot be validated without unacceptable accounting availability and look-ahead risk.

# Hash And Manifest Policy

Hash algorithm:

`SHA256`

Hash:

- raw snapshot files
- security-master files
- corporate-action files
- normalized formal evidence files
- schemas
- manifests

Each capture batch manifest must include:

- capture_id
- capture_date
- capture_timestamp
- source
- schema_version
- file inventory
- file hashes
- row counts
- security counts
- earliest source timestamp
- latest source timestamp
- missing components
- warnings
- capture status
- code/config version

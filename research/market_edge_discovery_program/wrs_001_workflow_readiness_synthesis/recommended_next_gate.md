# Recommended Next Gate

Recommended next stage:

**WPC-001: Workflow Portfolio Construction Protocol**

Purpose:

Define how the UC-3 workflow would be converted into a fixed, non-optimized research portfolio process.

This must be a protocol stage only.

It should define:

- rebalance frequency
- holding overlap treatment
- position count limits
- equal-weight versus volatility-aware treatment
- cash handling
- delisting/missing data policy
- transaction timing
- portfolio return accounting

No production deployment is authorized.

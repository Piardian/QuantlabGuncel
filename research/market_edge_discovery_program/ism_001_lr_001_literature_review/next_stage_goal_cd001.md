# ISM-001 / CD-001 Construct Definition

Purpose:

Freeze one precise Industry Momentum construct based on LR-001.

CD-001 must decide:

- Industry taxonomy.
- Point-in-time or static membership policy.
- Industry return weighting.
- Formation window.
- Skip-month convention.
- State output.
- Missing-data rules.
- Minimum industry size.
- Whether construct output is industry-level, stock-level, or both.

Forbidden:

- Implementing code.
- Running backtests.
- Optimizing parameters.
- Claiming alpha.
- Evaluating predictive validity.
- Evaluating economic value.

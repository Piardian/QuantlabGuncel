# Measurement Families

| family | description | CD-001 risk |
|---|---|---|
| Industry portfolio rank | Rank industry portfolios by past returns | Requires taxonomy and weighting |
| Stock by industry score | Assign stocks their industry momentum score | Requires membership mapping |
| Industry-adjusted stock momentum | Separate stock and industry components | Requires decomposition policy |
| Lead-lag industry momentum | Use related industry returns | Requires relation graph |
| Sector momentum | Coarse industry grouping | Lower granularity, possible information loss |
| Peer / text-based industry momentum | Defines peers using text similarity | Higher implementation complexity |

LR-001 does not select among these families.

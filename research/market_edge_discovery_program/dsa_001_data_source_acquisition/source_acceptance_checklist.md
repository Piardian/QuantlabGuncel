# Source Acceptance Checklist

## Mandatory Requirements Before Any Future BFL-002 Or Fundamental/Event Research

- [ ] Licensed source access confirmed.
- [ ] Data dictionary acquired.
- [ ] Sample schema inspected locally.
- [ ] Historical security existence separated from investable universe membership.
- [ ] Point-in-time universe membership effective dates verified.
- [ ] Active/inactive and delisted coverage verified.
- [ ] Delisting dates and terminal treatment verified.
- [ ] Permanent identifier history verified.
- [ ] Ticker history verified.
- [ ] Corporate-action methodology verified.
- [ ] Financial statement observation/availability dates verified where fundamentals are used.
- [ ] Earnings announcement dates/timestamps verified where PEAD is used.
- [ ] Analyst expectation forecast timelines verified where expectations are used.
- [ ] Historical industry classifications verified where ISM bridge is used.
- [ ] Reproducible extraction process documented.
- [ ] No performance metric inspected during source selection.

## Immediate Fail Conditions

- Current-only universe.
- Present-day industry classification backfilled historically.
- No delisted-security representation.
- No PIT financial statement availability for fundamental constructs.
- No earnings/expectation timing for PEAD.
- Source selected because performance looked good.

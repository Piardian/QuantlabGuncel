# Existing Construct Relationship Assessment

## CSM-001

CSM-001 already represents cross-sectional relative leadership. Any Dual Momentum rule using relative ranking directly consumes or closely replicates this information family.

Relationship: **Direct component / substantial conceptual overlap.**

## TSM-001

TSM-001 already represents an asset's own intermediate-horizon trend or absolute momentum state. Any Dual Momentum rule using an absolute return or trend condition directly consumes this information family.

Relationship: **Direct component / substantial conceptual overlap.**

## ISM-001

ISM-001 represents industry-level cross-sectional leadership and laggard states. It could define one possible ranked universe for a Dual Momentum workflow, but that is not inherent to the general candidate.

Relationship: **Potential implementation layer, not a defining independent mechanism.**

## Assessment

The completed constructs already contain the candidate's core information dimensions. The unresolved scientific question concerns their conditional combination, incremental information and workflow interaction. That question belongs to a comparison or composite-study protocol rather than a new independent construct lifecycle.

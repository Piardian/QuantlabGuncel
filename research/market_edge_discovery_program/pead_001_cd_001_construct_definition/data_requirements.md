# Data Requirements

PEAD-001 requires data that is not currently present in the repository.

Required dataset characteristics:

- Point-in-time earnings announcement events.
- Pre-announcement analyst consensus expected EPS.
- Actual EPS released at announcement.
- Announcement timing or session classification.
- Split-adjusted pre-announcement price reference.
- Security identifier mapping.
- Trading calendar.

Repository inspection found no existing local earnings or analyst estimate dataset satisfying these requirements.

IM-001 must therefore begin with dataset ingestion and verification before construct calculation.

# DVB-001 Owner Action Checklist

DVB-001 cannot be completed by code alone. The following owner actions are required before SLA-002 can verify an acquired source.

## Owner Actions

1. Select intended budget tier.
2. Choose candidate vendor/product stack.
3. Create vendor account if needed.
4. Select product plan or request quote.
5. Confirm license terms for local storage and automated research.
6. Complete payment or entitlement setup if approved.
7. Generate API credential or access token.
8. Store credential securely outside tracked research reports.
9. Provide data dictionary, account entitlement page, or vendor documentation.
10. Authorize SLA-002 to retrieve minimal non-formal validation samples.

## Required Owner Decision

Exactly one:

- `APPROVE_VENDOR_BUDGET`
- `APPROVE_EXPLORATORY_LOW_COST_STACK`
- `DEFER_VENDOR_DECISION`
- `REJECT_VENDOR_SPEND`

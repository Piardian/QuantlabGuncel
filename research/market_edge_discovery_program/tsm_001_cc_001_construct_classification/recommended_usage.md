# Recommended Usage

Supported by evidence:

- Use TSM-001 as a signed intermediate-horizon own-trend state descriptor.
- Use TSM-001 as a risk-state input for volatility and drawdown-risk research.
- Use TSM-001 in construct comparison studies against other validated market-risk constructs.

Partially supported:

- Use TSM-001 as a simple risk-control context variable, subject to additional economic validation.

Not supported:

- Use TSM-001 as a standalone expected-return alpha signal.
- Use TSM-001 as a production strategy without further validation.

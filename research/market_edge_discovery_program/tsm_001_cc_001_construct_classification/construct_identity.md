# Construct Identity

TSM-001 is not classified as a cross-sectional ranking construct.

TSM-001 is not classified as a volatility-scaled trend-following trading system.

TSM-001 is classified as:

**Raw 12-1 Time-Series Momentum State**

Scientific identity:

**Risk-State / Own-Trend Construct**

The construct measures whether each security is in a positive or negative intermediate-horizon own-trend state, using only its own adjusted-close history.

# Decision Framework

WOR-002 must conclude exactly one:

- Reproduced
- Partially Reproduced
- Not Reproduced
- Inconclusive

## Reproduced

Use only if the core CWS-001 nested workflow pattern is observed in non-overlapping OOS data.

## Partially Reproduced

Use if the relationship remains directionally similar but materially weaker or less stable.

## Not Reproduced

Use if the OOS data contradict the CWS-001 nested workflow interpretation.

## Inconclusive

Use if available OOS data are insufficient or required frozen outputs cannot be reconstructed.

## Forbidden Decision Language

WOR-002 must not conclude:

- Alpha confirmed
- Production approved
- Portfolio utility proven
- Strategy improved
- Economic value established

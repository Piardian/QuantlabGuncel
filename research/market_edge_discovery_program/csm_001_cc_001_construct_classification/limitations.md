# Limitations

- CC-001 synthesizes existing evidence only and does not run new analyses.
- The research used a current S&P 500-style universe, not survivorship-free historical constituents.
- Data quality depends on Yahoo adjusted-close availability.
- EV-001 used a simplified fixed workflow and fixed 10 bps transaction cost.
- No capacity, liquidity, tax, borrow, market-impact or live execution model was evaluated.
- No production deployment recommendation is made.
- Final scientific closure still requires FSR-001.

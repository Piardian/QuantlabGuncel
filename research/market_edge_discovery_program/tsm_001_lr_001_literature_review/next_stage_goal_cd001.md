# TSM-001 / CD-001 Construct Definition

## Purpose

Freeze one precise Time-Series Momentum construct definition.

## Required Decisions

CD-001 must specify:

- Target universe
- Price input
- Formation horizon
- Signal timing
- Whether volatility scaling is included or excluded
- Output state or score
- Eligibility rules
- Missing data policy
- Determinism requirements

## Forbidden

- No empirical testing
- No parameter optimization
- No backtesting
- No economic validation
- No production recommendation

## Success Criterion

Two independent researchers must be able to implement TSM-001 identically from the CD-001 specification.

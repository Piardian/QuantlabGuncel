# Scientific Importance Assessment

Industry Momentum is scientifically important because it tests whether momentum is partly a group-level phenomenon.

Unlike CSM, which ranks individual securities by their own trailing returns, ISM asks whether industry membership and industry-level return persistence contain independent information.

This is important for the Market Edge Discovery Program because previous momentum-family studies produced mixed outcomes:

- CSM-001 completed full lifecycle and remained economically only partially supported.
- TSM-001 behaved more like a risk-state / own-trend construct than a return edge.
- RSM-001 was mechanistically valid but predictively unsupported.

ISM-001 therefore provides a logically distinct next question within the momentum family.

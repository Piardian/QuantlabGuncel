# Incremental Value Assessment

## Assessment

Expected incremental research value is HIGH, but empirically unproven.

## Rationale

The existing Market Signal Discovery Program mainly validated risk-state constructs. Cross-Sectional Momentum is an edge-mechanism candidate and therefore expands the research program into a different scientific category.

## Boundary

CPP-008 concluded that the current construct ecosystem has only a limited pairwise architecture. Therefore RP-001 cannot claim that CSM provides independent information relative to existing constructs. It can only state that CSM is conceptually distinct and scientifically worth investigating.

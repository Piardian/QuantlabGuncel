# GOAL

Begin:

CIP-003

Construct Interaction Study

CSM-001 x RSM-001

## Mission

Both CSM-001 and RSM-001 have completed independent scientific lifecycles.

The purpose of CIP-003 is not to revalidate either construct.

The purpose is to determine whether raw cross-sectional momentum and residual momentum provide overlapping, incremental, or complementary scientific information.

## Primary Research Question

Does RSM-001 contribute statistically meaningful incremental information beyond CSM-001, and does their interaction justify a refined momentum-family workflow?

## Frozen Inputs

Use only the frozen outputs and evidence from:

- CSM-001
- RSM-001

No construct definitions, parameters, implementations, thresholds or evidence may be modified.

## Required Analyses

Perform:

1. Information overlap analysis
2. Incremental information analysis
3. Conditional predictive analysis
4. Interaction-state analysis
5. Agreement / disagreement matrix
6. Raw-vs-residual leadership assessment
7. Conflict-region assessment
8. Robustness analysis
9. Scientific interpretation

## Interaction Matrix

Evaluate:

- CSM_HIGH x RSM_HIGH
- CSM_HIGH x RSM_LOW
- CSM_LOW x RSM_HIGH
- CSM_LOW x RSM_LOW

and predefined intermediate states where appropriate.

## Allowed Conclusions

Exactly one:

- Strongly Complementary
- Partially Complementary
- Mostly Redundant
- Independent
- Inconclusive

## Forbidden

Do not:

- redefine CSM-001
- redefine RSM-001
- create a new construct
- optimize parameters
- build trading strategies
- perform portfolio optimization
- recommend production deployment
- claim alpha

## Success Criteria

CIP-003 is complete only if it objectively determines whether raw stock-level cross-sectional momentum and residual stock-level momentum represent complementary scientific mechanisms or largely overlapping information.

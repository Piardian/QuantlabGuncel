# Data Feasibility Risk Assessment

RSM-001 has moderate data risk.

Required data:

- Security return panel.
- Public factor return data.
- Risk-free rate if excess returns are used.
- Sufficient historical observations for rolling regressions.

Major risks:

- Factor model choice affects residuals.
- Regression window choice introduces researcher discretion.
- Missing return history can bias residual estimates.
- Factor data must be aligned without look-ahead.

Risk level:

**Moderate**

This is materially lower than PEAD-001 and PROF-001 because RSM can be constructed primarily from price returns and public factor data.

# BRD-001 / EV-001: Volatility Targeting Analysis

## Use Case

UC-2 Volatility Targeting.

## Policy

BRD policy:

- LOW_BREADTH target volatility: 8%
- MID_BREADTH target volatility: 12%
- HIGH_BREADTH target volatility: 12%
- maximum exposure: 1.00

Benchmark:

- Static 12% volatility target
- maximum exposure: 1.00

## Results

| Metric | BRD Policy | Benchmark | Delta |
| --- | ---: | ---: | ---: |
| CAGR | 0.0893 | 0.0948 | -0.0055 |
| Annualized volatility | 0.1049 | 0.1141 | -0.0092 |
| Max drawdown | -0.1308 | -0.1555 | +0.0246 |
| Downside volatility | 0.0809 | 0.0874 | -0.0065 |
| Average exposure | 0.8024 | 0.8387 | -0.0363 |

## Assessment

BRD-001 improved realized volatility management and drawdown control relative to static volatility targeting.

CAGR was modestly lower.

# Robustness Analysis

## Purpose

Evaluate whether EV-001 economic utility remains stable across fixed historical blocks.

## Periods

The study used four fixed blocks:

- 2011-2014
- 2015-2018
- 2019-2022
- 2023-2025

## Robustness Summary

| Use Case | Average Improved Risk Metrics Per Period | Interpretation |
| --- | ---: | --- |
| UC-1 | 2.25 / 3 | Mostly robust |
| UC-2 | 3.00 / 3 | Robust |
| UC-3 | 0.75 / 3 | Weak |
| UC-4 | 3.00 / 3 | Robust risk reduction, but return penalty remains |

## Interpretation

Supported by evidence:

UC-2 is the most robust risk-management workflow.

Supported by evidence:

UC-1 provides mostly robust risk budgeting utility.

Partially supported:

UC-3 lacks sufficient period robustness despite favorable full-sample metrics.

Partially supported:

UC-4 is robust for risk reduction but economically incomplete because of the CAGR penalty.
